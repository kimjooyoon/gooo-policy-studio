현재 모듈과 CI·릴리스 빌드는 Go 1.27.2를 사용합니다. 컴파일러 소스는

이 깨끗한 소스로 다시 생성했고 `--check`도 통과했습니다. 생성된 두 정책 함수와
전달 어댑터의 바이트는 그대로이며, 두 `generation.json`은 새 컴파일러의 실제

이 관측은 위의 10월 7일 브라우저 검사를 다시 수행했다는 뜻으로 확장하지 않습니다.

## API·자동화 자동 검증 — 2026-10-13

Go 1.27.2에서 전체 vet·race 검사와 서버/자동 검사 실행 파일 빌드가 통과했습니다.
자동화용 HTTP 검사 경로를 추가한 뒤에는 해당 HTTP race 검사를 다시 통과했습니다.
화면의 실제 이벤트 처리기를 구동한 Node 테스트 21개도 통과했습니다.
Gooo 소스, 생성 코드와 컴파일러 고정 리비전은 변경하지 않았습니다.

새 검사는 사례 순서·필수 필드·중복 ID, Unicode 손실·중복 키·대소문자 별칭,
후반 행의 잘못된 입력, 재계산한 외부 해시와 불일치하는 결과·요약·근거,
기대값 불일치와 오래된 화면 응답을 다룹니다. 최대 256개의 이스케이프가 필요한
텍스트 입력에서 2 MiB를 넘는 완전한 보고서가 실제로 생성되며, 이를 4 MiB
재실행 한도 내에서 그대로 가져와 재실행하는 검사도 통과했습니다.

독립적으로 작성한 합성 사례 5개를 새 실행 파일로 실행하고 저장 보고서를
재실행했습니다. 두 관측 모두 일치 5개·불일치 0개, 새 승인 가능 1개였습니다.
이는 해당 입력의 실행 예산 분류이며 실제 고객의 승인이나 비용 절감 관측이 아닙니다.

Chrome의 Jooyoon 프로필에서 실제 로컬 서버를 확인했습니다.

- 원문 JSON 파일을 가져와 모든 사례의 입력 검증과 5개 결과 PASS 표시 확인.
- 변경 한도를 100만원에서 50만원으로 바꾸자 이전 보고서 다운로드가 무효화됨.
- 같은 기대값으로 다시 실행하자 전체 5개 결과를 보존하고 불일치 1개를 FAIL로 표시.
- 실제 보고서 다운로드 완료 확인; 저장한 JSON의 5개 입력·결과·해시를 별도로 읽음.
- 다운로드한 보고서를 다시 가져오자 원래 두 정책과 5개 결과를 재실행해 PASS로 복원.

이 검증은 데스크톱의 확인한 흐름에 한정됩니다. 모바일 실기기, 모든 브라우저,
고객 업무량·성능, 실제 API 인증이나 외부 자동화 효과의 안전성은 측정하지 않았습니다.
해시가 일치하는 전체 보고서의 일관된 재작성은 발행자 인증으로 구별할 수 없다는
한계도 실행 테스트에서 명시적으로 확인합니다.
