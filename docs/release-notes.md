프레임워크 없는 Gooo 승인 정책 시뮬레이터의 첫 공개 버전입니다.

- Gooo 소유의 승인 규칙 5개, 거절 이유와 정책 변경 분류
- 현재/변경 정책 비교, 규칙별 관측, 12개 사례 영향 비교
- JSON 실행 기록 내려받기, 가져오기, 출처 확인과 저장 재실행
- Gooo 선언·생성된 Go·생성 기록을 화면에서 확인
- Go 표준 라이브러리 서버와 내장 HTML/CSS/JavaScript
- 정수 금액 검증, 중복/누락/null JSON 거부, 동일 출처 제한
- 256개 조건/규칙 조합과 도메인·재실행·HTTP 테스트

각 운영체제의 실행 파일을 내려받아 실행한 뒤 http://127.0.0.1:8080 에 접속하세요.
macOS는 다운로드한 실행 파일에 `chmod +x`가 필요합니다. 서버 주소는 `-addr`로 변경합니다.

실험용 시뮬레이터이며 실제 결재나 송금에 연결되지 않습니다. 실행 기록의 해시는 서명이 아닙니다.
