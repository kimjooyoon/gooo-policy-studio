# 기계 클라이언트의 두 요청 예제

[실행 안내](../../docs/policy-client.md)는 새 비공개 디렉터리에 이 파일을 복사한 뒤
서버 초기화 → 명령 준비 → 제출 → 같은 명령 재시도까지 실행합니다.

`req-client-allow`와 `req-client-deny`는 모두 합성 내보내기 계획을 검사합니다.
둘의 초기 파일은 동일한 예상 SHA-256·다섯 조건을 만족합니다. 두 번째 요청의
명령을 준비한 뒤 복사본을 `artifact-changed.json`으로 바꾸면 실제 바이트와
예상 SHA-256이 달라져 서버가 거절 결과를 저장합니다. 실제 자료를 내보내지 않습니다.

토큰은 초기화할 때 새로 생성됩니다. 예제에 인증 정보는 없습니다.
만료 시각 2100년은 데모용이며 실제 정책의 유효기간을 의미하지 않습니다.
기존 예제 파일이나 실행 중인 서버의 snapshot을 변경하지 마세요.
