# 실제 산출물의 자동 정책 검증

[`bootstrap.json`](bootstrap.json)은 로컬 기계 게이트의 명시적 v2 초기 설정입니다.
[`artifact.json`](artifact.json)의 실제 바이트 SHA-256, 정확한 필드·타입·값,
필수 검증 다섯 개를 지정합니다. 합성 내보내기 계획이며 실제 데이터 내보내기를
수행하지 않습니다. 스키마·값 조건을 모두 만족하는 로컬 승인 전이만 허용합니다.

[설정과 실행 안내](../../docs/artifact-gate.md)를 따라 새 상태와 자격증명 파일을
만드세요. 예제의 `deadline_unix: 4102444800`은 2100년 1월 1일 UTC를 가리키는
데모 값입니다. 실제 구성에는 업무가 허용하는 만료 시각을 지정해야 합니다.
`max_age_seconds: 60`은 호스트가 실제로 읽은 관측의 최대 나이입니다.
JSON을 다시 저장하여 바이트가 바뀌면 운영자의 예상 SHA-256도 변경해야 합니다.

`machine.gooo`의 최종 `ArtifactGateAdmits` 활동은 기본 정책, 전체 검증 수, 사용 가능한
근거 수, 완료 판단, 승인 효과 및 거절 기록의 효과 예산을 결합합니다.
`admission-cases.json`은 31개 유한 기대값 사례이며 실제 컴파일러 실행·재실행과
전체 타입 필드를 검사합니다. 이 사례 집합이 임의 업무에 대한 안전 증명은 아닙니다.

생성 비교는 모든 메타데이터를 확인하며 관측 지연 시간과 알려진 생성 호스트
`darwin/arm64`·`linux/amd64` 표기만 제한적으로 분리합니다. 고정된 컴파일러
소스에 대응하는 두 관측된 Go 모듈 버전 표기도 구분하여 보존합니다. 원문 근거를
수정하거나 요청의 실제 시각·권위·효과 필드를 정규화하지 않습니다.
